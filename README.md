# Chaotic Alchemy · 炼金配方查询器

一个纯前端的小工具，基于 Java 随机数逻辑，按照你的 Minecraft 世界种子生成：
- 催化剂大师（Catalyst Mastermind）7 张卡片的正确配方顺序
- 混沌嬗变（Chaos Transmutation）两两配对的转换表

支持中英双语、可访问性增强、以及对“硅”和“银（特殊）”配方的强提醒（高亮并置顶显示）。

> 提示：你可以直接访问https://fhrnv1.github.io/Chaotic-Alchemy/ 使用。

---

## 功能特性

- Java 随机一致性
  - 自实现 `java.util.Random`（48-bit LCG）与 `nextInt(bound)`，模拟 0..5 的均匀分布
  - 种子解析：
    - 纯数字字符串 → 以 64-bit BigInt 解析
    - 非数字字符串 → 使用 Java `String.hashCode()`（32-bit）并符号扩展为 BigInt
- 结果展示
  - 催化剂大师：7 张卡片（6 种催化剂 + 混沌），每张 4 位序列
  - 混沌嬗变：38 项条目（6×6 基材 + 2 个特殊：硅/银），两两成对，避免两个特殊相互配对
  - “硅”和“银（特殊）”在混沌嬗变列表中高亮，并自动置顶
- 国际化（i18n）
  - 内置中文（zh-CN）与英文（en），下拉选择即可切换
  - 文案通过 `data-i18n` 自动替换，支持占位与按钮文本
  - 记住选择的语言
- 体验与可访问性（a11y）
  - 支持回车提交（表单 `submit`）
  - 内联错误提示且已国际化
  - 结果区域具备 `aria-live` 与可聚焦，读屏更友好
  - 明显的 `:focus-visible` 焦点样式
- 免依赖构建
  - 无需任何打包工具或后端，直接打开即可使用

## 算法与实现要点

- 种子解析（`parseJavaSeed`）
  - 纯数字字符串：尝试以 `BigInt` 解析为 64 位整数
  - 其他字符串：计算 Java `String.hashCode()`（32 位），再符号扩展为 `BigInt`
- Java 随机（`JavaRandom`）
  - 采用与 Java 一致的 48 位 LCG 状态与变换，`nextInt(6)` 生成 0..5
- 催化剂大师
  - 共 7 类（6 种催化剂 + 混沌），每类 4 位序列，范围均为 0..5
- 混沌嬗变
  - 0..37 共 38 个索引（0..35 为 6×6 基材；36=硅，37=银）
  - 打乱并两两成对，若最开始两项都为特殊则做一次调整，避免二者互相配对
  - 渲染时：
    - 硅/银的配对项添加 `.special-substrate` 类并带有徽章
    - 先绘制所有“特殊配对”，再绘制普通配对，实现“置顶”

## 国际化与无障碍

- 国际化
  - 文案位于 `i18n.js` 中的 `messages` 对象
  - 通过 `data-i18n` / `data-i18n-placeholder` / `data-i18n-button` 自动应用
  - 切换语言会触发 `locale-changed` 事件并重绘页面
- 无障碍
  - 输入与按钮具备键盘操作，错误提示使用 `role="alert"`
  - 结果区域使用 `aria-live="polite"` 并在生成后聚焦
  - 焦点使用 `:focus-visible` 强调，便于键盘导航

## 常见问题（FAQ）

- Q: 为什么大整数种子建议以“文本”输入？
  - A: JS 的 Number 是双精度浮点，超过 2^53 可能丢失精度。文本输入会按 BigInt 或 hashCode 路径解析，避免精度问题。
- Q: 与某些 Minecraft 版本/Mod 的字符串种子结果不一致？
  - A: 本工具采用“Java Random + 字符串种子按 `String.hashCode()`”的通用模型。不同版本/模组在字符串种子到 long 的映射上可能存在差异，若需严格复现某一版本，请提供细节以作适配。
